# 页面与交互说明

## v0.1 已实现

共 **6 个业务页面（总览 + 5 个模块占位页）、1 个 404 辅助页、0 个弹窗**。

| 页面 / 路由 | 展示内容 | 按钮或入口 | 跳转 / 行为 |
| --- | --- | --- | --- |
| 总览 `/` | 项目介绍、5 个模块卡片、真实服务连接状态、版本标识 | 了解个人档案、查看模块、重新检查 | 前两类跳转模块；重新检查调用 `/health`，检查中禁用按钮，最长等待 5 秒 |
| 用户与基础 `/profile` | 模块说明、负责人、3 项功能规划、待开发状态 | 返回总览、公共导航 | 返回 `/` 或切换模块 |
| 饮食营养 `/diet` | 同上，对应饮食模块 | 同上 | 同上 |
| 运动健身 `/exercise` | 同上，对应运动模块 | 同上 | 同上 |
| 睡眠监测 `/sleep` | 同上，对应睡眠模块 | 同上 | 同上 |
| 生理期管理 `/cycle` | 同上，对应生理期模块 | 同上 | 同上 |
| 404 `其他路径` | 页面不存在说明 | 返回总览 | 返回 `/` |

桌面使用左侧导航，手机使用横向导航。总览健康检查覆盖“检查中 / 已连接 / 未连接”三种状态，未连接时仍可浏览模块说明。所有功能规划均明确标注待开发，不展示虚构健康数据。

## v0.2 通用交互

1. 页面首次进入显示加载状态；无记录时显示空状态与“新增”按钮。
2. 尚无个人档案时，业务模块提示“请先建立个人档案”，按钮跳转 `/profile`；暂不开放记录提交。
3. 编辑弹窗提供“保存”和“取消”；取消不写入数据库。提交中禁用保存按钮，防止重复请求。
4. 服务端校验失败在表单旁展示原因并保留输入；请求失败可重试。
5. 保存成功关闭弹窗并刷新列表；删除先弹确认框，成功后刷新，取消保持原状。
6. 时间输入按 `Asia/Shanghai` 展示和解释；提交睡眠起止时间时带明确时区，具体字段见接口清单。

跳转关系：`总览 ↔ 各模块`，`各模块 ↔ 公共导航中的其他模块`，`各模块 → 编辑/删除弹窗 → 当前页面刷新`。
