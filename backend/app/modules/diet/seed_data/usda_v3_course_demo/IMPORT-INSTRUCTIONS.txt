- 营养为食材投料估算，非成品实测；成分与过敏原未完整核验。
- 课程批准不是医学或正式生产用途批准，也不是过敏安全证明。

- 不包含用户档案、饮食/饮水记录、数据库、密钥或完整USDA大数据集。
- SHA256SUMS.txt覆盖包内所有其他文件；manifest.json绑定数据、审批及来源材料。

Windows PowerShell（项目根目录打开终端，已安装Python 3.12 .venv及固定依赖）

cd backend
& ..\.venv\Scripts\python.exe -B -m app.modules.diet.seed_data.usda_v3_course_demo.demo_seed

上述默认命令只在新TemporaryDirectory中显式初始化基础结构和001～004、
创建明确标记为“开发演示档案（非真实用户）”的合法单档案profile_id=1并dry-run。
预计add=146,skip=0,conflict=0；不导入食物和菜谱，退出后清理临时库。
不使用环境默认数据库，不连接正式health.db，不补跑已有库迁移。

明确要保留新的课堂演示库并导入时（不会覆盖已有库）：

$resultJson = & ..\.venv\Scripts\python.exe -B -m app.modules.diet.seed_data.usda_v3_course_demo.demo_seed --create-demo --apply
if ($LASTEXITCODE -ne 0) { throw '演示创建或导入失败，停止' }
$result = $resultJson | ConvertFrom-Json -ErrorAction Stop
$demoDb = $result.database_path
$result | Format-List

每次--create-demo都会建立不同的系统临时目录health-diet-course-v3-*/demo.db。
仅接受配套SEED_DEMO_ONLY.json标记、固定v3 manifest、完整迁移、合法演示档案的库。
外键约束开启；来源冲突、用户修改、失效计划均停止，不覆盖。
普通app.modules.diet.import_data入口拒绝course_demo，不得改用途字段绕过保护。

重复导入预览（只使用刚才输出的真实路径）：

$previewJson = & ..\.venv\Scripts\python.exe -B -m app.modules.diet.seed_data.usda_v3_course_demo.demo_seed --database $demoDb
if ($LASTEXITCODE -ne 0) { throw '预览失败，停止' }
$preview = $previewJson | ConvertFrom-Json -ErrorAction Stop
$preview | Format-List

预计add=0,skip=146,conflict=0。如确需再次执行同一计划：

& ..\.venv\Scripts\python.exe -B -m app.modules.diet.seed_data.usda_v3_course_demo.demo_seed --database $demoDb --apply --confirm-database $demoDb --expected-plan-sha256 $preview.plan_sha256

网站启动（保留此终端，不使用旧v2工厂或默认app.main入口）：

$env:HEALTH_DIET_SEED_DB = $demoDb
$env:HEALTH_DB_PATH = $demoDb
