# 极简需求清单

**项目目标：** 开发一个个人健康记录工具，集中录入、查看和维护健康档案、饮食、运动、睡眠与生理期信息。

**核心功能（5 条，v0.2 实现）：**

1. 用户与基础：维护一个本地健康档案、生活偏好及手动追踪的累计型健康目标。
2. 饮食营养：手动增删改查饮食记录，按日汇总已填写的热量。
3. 运动健身：增删改查运动类型、时长与强度，按日汇总时长。
4. 睡眠监测：手动增删改查入睡/醒来时间与主观评分，计算跨夜睡眠时长。
5. 生理期管理：增删改查经期起止、流量、症状和情绪记录。

**不做什么：** 首轮不做注册登录、多角色权限、多人数据、AI 推荐、拍照/扫码、食物/动作资源库、设备接入、主动提醒、经期与排卵预测、医疗诊断和报告导出。

**关键规则（2 条）：**

1. 单个本地档案固定为 `id=1`，其他记录全部归属此档案；先建立档案再录入业务数据。
2. 服务端校验日期与数值：醒来晚于入睡、经期结束不早于开始、运动时长和食物份量大于 0；无效输入不保存。

**v0.1 交付边界：** 只做可运行骨架、五个模块入口、健康检查、空表初始化与文档；上述业务功能尚未实现。原文完整功能保留在 [后续规划](07-roadmap.md)。
