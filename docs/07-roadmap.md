# 原始需求与后续规划

依据用户提供的《软工需求分析.doc》，原文是 **5 个业务模块，每模块 6 项功能，共 30 项**。本次要求是准备 v0.1 初始骨架，因此原文作为需求素材保留，未把全部功能视为本次实现要求。

## 版本安排

| 阶段 | 交付 |
| --- | --- |
| v0.1 当前版本 | 文档、六张空表、前后端骨架、健康检查、首页与模块入口 |
| v0.2 核心业务 | 单人本地档案和目标、手动饮食/运动/睡眠/经期记录及基础汇总 |
| v0.3 及以后 | 按课程要求和时间，从以下扩展中选择；不默认全部承诺 |

## 原文功能逐项归属

| 模块 | v0.2 采用的基础部分 | 后续保留的扩展部分 |
| --- | --- | --- |
| 用户与基础 | ③健康档案（含病史、过敏、用药）；④目标设定与手动进度；⑤偏好文本配置 | ①注册、密码加密与账号状态；②登录、Token/JWT、多角色；⑥密码修改、授权与隐私开关；④自动追踪 |
| 饮食营养 | ①手动饮食记录；③用户已填写热量的每日合计 | ①拍照/扫码；②食物营养库；③完整营养素统计与达标率；④食谱推荐；⑤饮水与提醒；⑥饮食报告/导出 |
| 运动健身 | ①运动记录；④每日时长合计 | ②训练计划；③动作库和教学视频；④消耗/心率/趋势；⑤打卡与自动目标追踪；⑥运动报告 |
| 睡眠监测 | ①入睡/醒来记录；②仅主观评分 | ①深浅睡；②多维算法评分；③趋势与异常识别；④助眠内容；⑤作息提醒与闹钟；⑥睡眠报告 |
| 生理期管理 | ①经期起止、流量、症状；④每次经期的症状/情绪备注 | ②经期、排卵与易孕期预测；③阶段分析；④逐日症状/体温曲线；⑤关怀提醒；⑥规律性报告 |

表中的编号对应原文各模块的 1–6 项，基础版只采用明确列出的部分。用户模块首轮不做账号体系，其他模块暂以同一个本地档案关联。

原文额外提到的 **综合可视化仪表盘、异常预警与干预、跨模块联动推荐、统一报告导出、消息提醒中心、健康知识库** 均为可选后续方向，不属于 v0.1 或 v0.2 的交付承诺。

原文中的“换成”“可以加”等措辞按建议记录，不自动更改本次范围。若课程最终要求完整的 30 项功能，可按本表逐项新增需求、页面、表和接口；当前六张核心表只覆盖已约定的基础范围。
